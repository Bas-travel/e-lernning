# 03-P0 Screens

## Goal

Build the highest priority screens first.

## Recommended P0 coverage

Use the screens already defined in `01-screens-spec.md` and organize by product area:

### Learner
- Home
- Explore
- Course Detail
- My Learning
- Lesson / Video Player
- Quiz / Result
- AI Tutor
- Career / Portfolio

### Instructor
- Instructor Dashboard
- Course Builder
- Course Preview
- Revenue / Analytics

### Corporate / Admin
- Corporate Dashboard
- Employee Management
- Learning Paths
- Admin Dashboard
- Course Moderation
- Payment Management
- User Management

## Rule

Build in grayscale first, then apply colors after layout approval.
