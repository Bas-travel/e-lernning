# 01-Components

## Goal

Build reusable UI components before screen design.

## Suggested component groups

- Buttons
  - Primary
  - Secondary
  - Ghost
  - Outline
  - Icon button
- Inputs
  - Text input
  - Select
  - Search
  - Dropdown
- Cards
  - Course card
  - Lesson card
  - Score card
  - Employee card
  - Job card
- Navigation
  - Top bar
  - Bottom nav
  - Sidebar
  - Tabs
- Feedback
  - Toast
  - Banner
  - Alert
  - Empty state
- Data widgets
  - Progress bar
  - Rating
  - Tag / pill
  - Avatar

## Rule

Every component should be created once and reused across screen pages.
