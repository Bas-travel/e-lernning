# 01. Implementation Overview

## Product summary

AB LEARNING is a learning platform focused on career growth, skill development, and opportunity outcomes. The product is structured around learning journeys that combine content, assessment, guidance, and measurable progress.

## Core goals

- Help users acquire and validate skills
- Maintain clear learning momentum
- Make portfolio and career outcomes visible
- Provide instructors, admins, and corporate teams with actionable tooling

## Delivery model

The current implementation scope is designed for an MVP-style delivery sequence:

1. Foundation and design system
2. Core learner screens
3. Instructor and admin services
4. Corporate management flows
5. Performance, moderation, and reporting tasks

## Implementation priorities

### Phase 1: learning foundation
- Home
- Explore
- Course detail
- My Learning
- Lesson flow
- Quiz and result flow
- AI tutor shell

### Phase 2: business and operations
- Instructor dashboard
- Course management
- Corporate dashboards
- User management
- Payment views

### Phase 3: scale and reporting
- Admin analytics
- Moderation
- Reporting and operational views

## Executive note

The product should be implemented with a clear screen hierarchy and strong UI consistency. Avoid feature sprawl before the core learner experience is stable, polished, and validated.
