# 06. Delivery Checklist

## Pre-build checklist

- [ ] Design token set approved
- [ ] Core screen hierarchy signed off
- [ ] Figma components and states created
- [ ] API contract checked against UI needs
- [ ] Database model reviewed and aligned
- [ ] Existing mockup review notes considered

## UI checklist

- [ ] Buttons and CTAs consistent across views
- [ ] Card spacing and radii consistent
- [ ] Mobile and tablet layouts remain readable
- [ ] Empty / error / loading / success states implemented
- [ ] Accessibility review completed for key screens

## Backend checklist

- [ ] Routes map to OpenAPI contract
- [ ] Response shapes validated
- [ ] Admin and learner flows implemented with correct permissions
- [ ] Payment and moderation flows reviewed

## Quality checklist

- [ ] Code review completed
- [ ] App runs locally in dev environment
- [ ] API and DB integration are working
- [ ] High-priority flows tested end-to-end
- [ ] Design review feedback reflected in implementation

## Final sign-off

Before release, confirm:

- product direction remains aligned
- Figma and app implementation match approved screens
- tokens are implemented consistently
- core flows are stable and usable

---

This checklist is intended to prevent drift between product intent, visual design, and implementation progress.
