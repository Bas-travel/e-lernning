# 01. Product Vision and Experience Principle

## Product intent

AB LEARNING is an AI-powered career learning platform designed to help users learn, practice, validate skills, and move toward job opportunities. The design should feel credible, modern, and trust-building, while remaining approachable and motivating for learners.

## Core promise

Learn → Practice → Prove → Get Opportunity

## Experience goals

### 1. Clarity first
The user must understand the next action immediately. Primary buttons, CTA structure, and navigation should be obvious without confusion.

### 2. Momentum and motivation
The UI should reinforce achievement through progress, streaks, completion states, and visible milestones.

### 3. Trust and professionalism
Cards, charts, payment flows, and admin tools must feel dependable and enterprise-safe.

### 4. Mobile-first clarity
The mobile experience should prioritize the learning journey and one-handed actions. Desktop builds depth, analytics, and admin power tools.

### 5. AI as an enabler
AI features such as tutor interaction, skill assessment, and personalized recommendations should feel supportive and helpful, not gimmicky.

## User groups

- Learners
- Instructors
- Corporate admins
- Employers
- Platform administrators

## Design tone

- Confident
- Clean
- Professional
- Human-centered
- Friendly but structured

## Key UI principles

### Layout
- Strong alignment and spacing consistency
- Clear visual grouping for information architecture
- Content priority driven by task completion and motivation

### Interaction
- Buttons must read as clear primary/secondary actions
- State transitions must be obvious and consistent
- Overlays should be used to reduce friction without blocking flow

### Accessibility
- Color contrast must meet WCAG AA minimum for key UI text and actions
- Icons and labels should be legible and contextual
- Status states must be clear without relying on color alone

## Product priority order

1. Learner product value
2. Instructor workflow
3. Corporate domain tools
4. Employer and admin reporting
5. Supportive features and secondary flows

---

## Handoff note

This product is expected to feel like a polished learning platform, not a generic course marketplace. The visual system should reinforce progress, trust, and capability-building throughout the experience.
